
Zenvia Industrial and Home Automation — Simulation Projects

This document contains links to the simulation platforms used to develop and test different modules of Zenvia.

## 1. ESP32 Hardware Simulation — Wokwi

**Project Link:** [Open Wokwi Simulation](https://wokwi.com/projects/478604948130473985)
**Description:**

This module simulates and validates the core operating logic of Zenvia's industrial machine control system. It evaluates safety conditions before allowing machine operation and tests how the system responds to gesture-based commands under different distance conditions.

**Purpose:** Simulates the ESP32-based industrial control circuit, including distance monitoring with the HC-SR04 ultrasonic sensor and LED indicators for machine status.

**Project Status:** Software simulation and logic validation completed for the tested scenarios; physical machine integration and real-world safety validation remain separate stages.

## 2. Additional Simulation — Tinkercad AI

**Project Link:** [Open Door Lock Simulation](https://app.tinkered.ai/p/e9fa660f-59da-4a02-b893-a6959ee57d93)
**Description:**

This project demonstrates a smart door lock system designed to improve door access control through an electronic locking mechanism. The simulation provides a platform to explore the system's operation and test its access-control workflow before physical hardware implementation.

**Purpose:** To demonstrate the concept of automated door locking and controlled access through a simulation-based prototype.

**Project Status:** Simulation-based prototype.


## 3. Additional Simulation — Tinkercad AI

**Project Link:** [Open Tinkercad Project](https://app.tinkered.ai/p/03009108-6fae-484a-9c9e-addac7b4f725)
**Description:**
This project demonstrates a human presence detection system that combines thermal sensing and motion detection to identify whether a person may be present in a monitored area. The thermal sensor helps detect heat associated with a person, while the motion sensor detects movement. Combining these sensor inputs can improve presence-detection decisions compared with relying on motion detection alone.

**Purpose:** To prototype a sensor-based human presence detection system and evaluate how thermal and motion sensing can work together for automated monitoring.

**Project Status**: Simulation-based prototype; physical hardware implementation and real-world accuracy testing are separate stages.

## 4. Additional Simulation — Tinkercad AI

**Project Link:** [Open Tinkercad Project](https://app.tinkered.ai/p/a0ebf658-6ac7-4bf1-a209-3a296712aeb0)
**Description:**
This project demonstrates a smart courier box designed to receive and secure parcel deliveries when the homeowner is away. The system aims to reduce missed deliveries and prevent packages from being left unattended and exposed outside the home.

**Purpose:** To prototype an automated parcel-receiving solution that improves delivery convenience and package security for homes.

**Project Status:**  Simulation-based prototype; physical implementation and real-world security testing are separate stages.
